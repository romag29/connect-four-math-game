# Connect Four Math Game

A terminal-based Connect Four game in Java featuring an interactive 
math challenge before every move.

## The Problem

There are not many free study games that have a variety of games other 
than matching games like Quizlet and Blooket and Kahoot.

## How It Works

Math Connect Four blends classic four-in-a-row strategy with arithmetic practice. 
Players take turns claiming a spot on a 6x7 grid, but with a twist: before every move, 
they must pass a "Math-Gate" by solving a randomly generated arithmetic problem
(addition, subtraction, or multiplication).
